쿠팡 가격 변동 상품을 찾고, 권한이 있는 판매처의 자사 상품 가격과 대조합니다.
서버 확인 중

1. 관리자 인증

기존 관리 토큰으로 접속합니다.

2. 날짜별 크롤링 파일 업로드

실제 크롤링 형식의 XLSX 또는 CSV를 올리세요. 파일명에 YYYYMMDD 날짜가 있으면 자동 인식합니다. 업로드한 배치는 별도 보관되며 같은 날짜 데이터는 자동 덮어쓰지 않습니다.
필수 열: 옵션ID, 노출ID, 아이템ID, 판매가, 상품명

3. 판매처별 자사 상품·가격 파일 업로드

각 판매자센터에서 권한에 따라 내보낸 상품 목록을 올리세요. 상품명과 판매가가 있는 XLSX 또는 CSV를 지원합니다. 업로드 후 행 단위로 처리합니다. 성공한 최신 파일만 현재 가격표로 사용하며 기존 파일과 기록은 보존합니다.
상품명·판매가 열이 필요합니다. 바코드 또는 판매자상품코드가 있으면 더 정확히 연결됩니다.

4. 날짜 배치 비교 및 가격 후보 조회

쿠팡 날짜별 배치를 선택해 비교하세요. 판매처 가격표를 올리면 가격이 변동한 쿠팡 상품과 대조합니다.

쿠팡 상품 URL은 /vp/products/{노출ID}?vendorItemId={옵션ID} 규칙으로 생성합니다. 이름으로 후보를 연결할 때는 기종·색상·구성을 제외한 상품명 앞부분 핵심어가 2개 이상 일치해야 합니다. 기종이나 수량이 서로 다르면 제외하고, 바코드가 정확히 일치할 때만 앞부분 단어 비교를 건너뜁니다. 후보는 원인 확정이 아닌 확인용 단서입니다. 사이트별 자동 수집이나 접근 제한 우회는 하지 않습니다.
