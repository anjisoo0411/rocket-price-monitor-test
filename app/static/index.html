1. 상품 목록 등록 / 갱신

‘추적대상_옵션IDURL’ 시트를 읽어 SKU, 바코드, 판매가, 옵션 ID, ITEM ID, 노출 ID, 쿠팡 상품 URL을 저장합니다. 기존 가격 이력은 유지됩니다.
상품 목록을 등록하거나 갱신할 수 있습니다.

2. 확인한 쿠팡 가격 이력 등록

가격 비교를 위해 동일 SKU의 쿠팡 가격 기록이 최소 2회 필요합니다. 엑셀의 ‘판매가’는 참고용 기준가로만 저장하며 쿠팡 소비자 노출가격으로 간주하지 않습니다.
실제로 확인한 쿠팡 가격만 등록하세요.

3. 쿠팡 가격 자동 수집 및 변동 조사

쿠팡 공식 Open API의 옵션별 salePrice를 수집합니다. 실제 소비자 노출가격과 다를 수 있지만, 동일 API 지표의 변동 여부를 감지하는 용도로 사용합니다.
관리자 인증 후 API 연결 테스트를 진행하세요. 전체 수집은 시험 수집 검증 후 사용합니다.
