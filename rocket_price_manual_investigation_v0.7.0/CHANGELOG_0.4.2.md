# 0.4.2

- 쿠팡 공식 Open API 옵션별 수량/가격/상태 조회를 추가했습니다.
- HMAC SHA256 서명 및 vendor ID / KR market 헤더를 적용했습니다.
- API 연결 1개 테스트, 5개 시험 수집, 전체 수동 수집 및 진행률 조회를 추가했습니다.
- 초당 약 3회 이하로 순차 호출하며 401/403/429 발생 시 즉시 중단합니다.
- `salePrice`는 가격 변동 감지 지표로 저장하며 소비자 노출가격이라고 보장하지 않습니다.
- 기존 상품 및 가격 이력 데이터는 삭제하거나 변경하지 않습니다.
