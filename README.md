# 쿠팡 가격 변동 조사 도구 (0.4.2)

필요할 때 관리자가 직접 조사하는 자사 상품 전용 도구입니다. 정기·자동 감시, 경쟁사 가격 수집, 이메일 알림은 새 운영 흐름에서 사용하지 않습니다.

## 새 운영 흐름

1. `data/rocket_price_product_master.xlsx` 또는 최신 상품 엑셀을 웹 화면에서 업로드합니다. `추적대상_옵션IDURL` 시트의 9,583개 추적 대상만 가져옵니다.
2. 쿠팡에서 실제로 확인한 가격을 CSV로 등록합니다. 같은 SKU에 대해 최소 2회의 가격 기록이 있어야 변동 여부를 비교할 수 있습니다.
3. `가격 변동 조사 실행`을 누르면 SKU별 최근 2회의 쿠팡 가격 스냅샷을 비교합니다.
4. 가격이 바뀐 SKU만 결과에 나타나며, 네이버 쇼핑 검색 링크로 동일 자사 상품을 사람이 확인합니다.

## 저장되는 상품 식별 정보

- SKU ID, 상품명, 바코드, 기준 판매가
- 옵션 ID (`vendorItemId`), ITEM ID, 노출 ID
- 쿠팡 URL (`/vp/products/{노출ID}?vendorItemId={옵션ID}`)

기준 판매가는 참고용 원본 정보이며 쿠팡 소비자 노출가격 스냅샷으로 자동 등록하지 않습니다.

## 가격 CSV 형식

필수 컬럼: `SKU ID`, `판매처`, `가격`
선택 컬럼: `배송비`, `URL`, `판매자`

새 화면은 `판매처`가 정확히 `쿠팡`인 행만 등록하고 다른 판매처 행은 제외합니다. 템플릿은 `data/coupang_price_import_template.csv` 및 화면의 CSV 양식 받기에서 확인할 수 있습니다.

## 중요한 데이터 접근 제한

이 버전은 쿠팡 또는 네이버 웹페이지에 자동 접속하거나 크롤링하지 않습니다. 쿠팡 이용약관은 회사의 사전 승인 또는 협의 없이 로봇·스크레이퍼 등 자동화 수단으로 사이버몰에 접근하는 행위를 제한합니다. 네이버도 명시적 허용·사전 승낙 또는 허용된 API/robots 범위 외의 자동화 접근과 정보 수집을 제한합니다.

따라서 쿠팡 소비자 노출가격 수집은 쿠팡의 사전 승인 또는 별도 허용된 데이터 공급 경로를 확보한 뒤에만 연결해야 합니다. WING 판매자 API의 `salePrice`는 로켓배송 소비자 노출가격과 동일하다고 검증되지 않았으므로 이 버전에서는 해당 API 가격 수집 경로를 제거했습니다.

네이버 개발자센터의 기존 쇼핑 검색 API는 2026-07-31 종료되었습니다. 공식 공지에서 쇼핑 검색 API는 이관 대상에서 제외되며 대체 API가 제공되지 않는다고 안내합니다. 따라서 본 버전은 네이버 쇼핑 검색 링크를 열어 사람이 결과를 확인하도록 구성했습니다.

네이버 검색 결과의 가격이 쿠팡 가격 변동의 원인이라고 단정하지 않습니다. 가격 시점 비교는 원인 후보를 찾기 위한 참고 신호입니다.

## 기존 데이터베이스 호환

앱 시작 시 `products` 테이블에 `option_id`, `item_id`, `exposure_id`, `source_sale_price` 컬럼이 없으면 추가하는 비파괴 마이그레이션을 수행합니다. 기존 상품 행과 가격 이력은 삭제하지 않습니다.

## 실행 및 배포

기존 프로젝트와 동일하게 FastAPI / SQLAlchemy 기반입니다. 로컬 실행은 Python 3.12+ 환경에서 다음 명령을 사용합니다.

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

클라우드에 배포하기 전 `ADMIN_TOKEN`을 안전한 값으로 설정하고 HTTPS를 사용하세요. 기존 Render 서비스에는 이 ZIP을 먼저 별도 브랜치/테스트 서비스에서 검증한 뒤 반영하는 것을 권장합니다. `render.yaml`은 기존 인프라 설정을 유지하므로, 배포 전에 Render 대시보드에서 웹 서비스와 데이터베이스의 요금제를 확인하세요.

## 주요 API

- `GET /api/health` 서버 상태
- `GET /api/summary` 상품/가격 이력 요약
- `GET /api/products?q=&page=1&limit=50` 상품 검색 및 식별 정보
- `POST /api/import-xlsx/start` 상품 엑셀 등록 작업
- `GET /api/import-xlsx/status/{job_id}` 엑셀 등록 진행률
- `POST /api/import-prices-csv` 확인한 쿠팡 가격 CSV 등록
- `POST /api/investigations/changed` 최근 2회 가격 비교 및 변동 상품 추출
- `GET /api/products/{sku_id}/investigation` 개별 SKU 조사 정보
- `GET /api/export.csv` 가격 이력 내보내기

인증이 필요한 API는 `Authorization: Bearer <ADMIN_TOKEN>` 헤더를 사용합니다.

## 보안

쿠팡 Access/Secret Key 및 SMTP 비밀번호를 프런트엔드나 채팅에 입력하지 마세요. 이전 대화에서 노출된 쿠팡 키는 폐기·재발급하는 것이 안전합니다. 이 버전에서는 WING API 키를 사용하지 않습니다.


## Render 무료 테스트 환경 안내

이 저장소의 `render.yaml`은 기존 운영 서비스와 데이터베이스를 건드리지 않도록 `rocket-price-monitor-test` / `rocket-price-db-test`라는 별도 테스트 리소스를 생성하도록 구성했습니다. 두 리소스는 Render Free 플랜입니다.

주의: Render 무료 웹 서비스는 15분간 요청이 없으면 중지되고, 다시 접속할 때 기동에 약 1분이 걸릴 수 있습니다. 무료 Postgres는 생성 후 30일이 지나면 만료되므로 장기 운영 데이터 저장소로 사용하면 안 됩니다. 테스트가 끝나기 전에 가격 이력과 상품 데이터를 CSV로 내보내고 백업하세요.

무료 서비스는 로컬 파일시스템이 영구 저장되지 않지만, 이 앱의 운영 데이터는 PostgreSQL에 저장되도록 설정했습니다. Render 무료 플랜의 제한과 만료 정책은 배포 전에 공식 문서를 다시 확인하세요.
